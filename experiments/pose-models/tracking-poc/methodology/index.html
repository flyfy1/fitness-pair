HOW TO DECIDE WHAT IS BETTER

Compare the same job, on the same input.

01

Pick one outcome

Joint stability for tracking. False and missed events for actions. Perceived delay for a game. Keep these questions separate.

02

Keep conditions fixed

Use the same camera, framing, lighting and movements. Include slow/fast motion, occlusion and movements that should not trigger.

03

Record comparable evidence

Report joint loss, false/missed completions, recovery time and latency p50/p95. Inference time alone is not camera-to-screen delay.

What the evidence means

Public fixture: a real model processed a public image. Synthetic: known generated input exercised logic. Research: a source was reviewed. None establishes human tracking accuracy. No comparative human results are recorded in this catalog; participant recording requires consent.
